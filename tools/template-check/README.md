# Template check

Verifies that every file and section a skill cites actually exists in a workspace.

```bash
# check this workspace
python3 tools/template-check/check_refs.py .

# check what a NEW client actually gets
git clone <this template's repo URL> /tmp/fresh
python3 /tmp/fresh/.claude/skills/onboard/detect-workspace.py
python3 tools/template-check/check_refs.py /tmp/fresh
```

Run the fresh-clone version after any change to a skill's references, and before
telling a client to pull.

## What it catches

A skill saying "read `references/foo.md` → Bar" when the file has no such section,
or no such file ships. Both fail silently: the skill runs, finds nothing, and
carries on with worse output. That is how a client's results quietly degrade
without an error anywhere.

## Known-good misses

Three things are *correctly* absent from a fresh workspace, so ignore them:

- `daily-log/YYYY-MM-DD.md` — a date placeholder, not a real path
- `references/learning/spent-phrases.md` — generated by `tools/spent-phrases/`
- any operational compliance ruleset — created by `/onboard` for regulated owners only

Everything else it reports is a real gap.
